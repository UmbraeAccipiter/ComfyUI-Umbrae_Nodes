# umbrae_nodes wildcards

Put `.txt` (one option per line) and `.yaml` wildcard files here.
`emotions.txt` is used as `__emotions__`; subfolders become `__folder/name__`.

"wildcard processor [umbrae]" reads this folder AND Impact Pack's custom
wildcards folder (if it exists). When both have the same wildcard name, the
file in THIS folder wins. Press "Refresh Wildcards" on the node after editing.
(.md files are ignored.)
